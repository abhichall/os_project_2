# Rutgers CS416 Project 2: User-Level Thread Library and Scheduler

This project implements a user-level thread library with thread creation,
yielding, joining, exiting, mutexes, and timer-based preemption. Its scheduler
supports PSJF and MLFQ and records context-switch, response-time, and
turnaround-time statistics.

Focused tests have been run on iLab. Benchmark comparisons with Linux pthreads
and the project report remain to be completed.
